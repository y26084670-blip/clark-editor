# Три параллельные ВТСП-ленты, 130 × 12 × 0,1 мм

Распакуйте эту папку в каталог заданий CLARK и откройте её в Editor.
Исходные данные находятся в `input3XX`; запуск — обычным способом через решатель.

- Зазоры 1 мм; токи лент: 295,491 / 309,018 / 295,491 А (сумма 900 А).
  На каждом торце каждой ленты задан контактный ток; общих шин нет.
- Шаг сетки: 0,333 мм вдоль, 0,273 мм поперёк, два слоя по 0,05 мм.
- Симметрии восстанавливают три полные ленты из двух показанных частей.
  Независимых ячеек проводников 12 870; основных матриц около 44,4 GiB
  суммарно по MPI-процессам, плюс рабочая память.
- Время 0–5 с, шаг 0,01 с. Стартовый ток равен нулю.

Это приближённый перенос COMSOL: токи ветвей заданы по его DC-результату,
используется свободное пространство, закон по толщине приближён двумя слоями.
Формат, геометрия, контакты и пересчёт материала проверены; расчёт CLARK не запускался.

[Постановка, материал и условия сопоставления](docs/AI_MODEL.md).
Параметры и проверка: `case.json`, `validation.json`.
