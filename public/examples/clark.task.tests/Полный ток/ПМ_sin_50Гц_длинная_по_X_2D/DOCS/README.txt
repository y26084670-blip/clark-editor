Вытянутая проводящая плита и неподвижный магнит — 3D, синус 50 Гц
Подготовлено: 2026-11-01 21:39 UTC+3

Постановка
Элемент 1: немагнитная проводящая плита 120 x 30 x 10 мм.
Координаты: X от -60 до +60, Y от -15 до +15, Z от -10 до 0 мм.
Проводимость 40 МСм/м, относительная магнитная проницаемость 1.
Разбиение D1 x D2 x D3 = 60 x 15 x 5; 4500 ЭО по 2 x 2 x 2 мм.
Внешние грани изолированы: MED=[-1,-1,-1,-1,-1,-1], useMED=true.

Элемент 2: магнит 80 x 5 x 20 мм; высота 20 мм направлена по Z.
Центр нижнего торца (-10,-5,6) мм, зазор над плитой 6 мм.
Глобальные границы: X от -50 до +30, Y от -7.5 до -2.5,
Z от 6 до 26 мм. Плита выступает за торцы магнита по X на 10 и 30 мм.
Магнит неподвижен: indMove=0, moves.txt пуст.
Однородная заданная намагниченность: один ЭО, dp=[1,1,1],
одна строка заданных источников M0=(0,0,1000) кА/м.
Реакция поля на величину заданной M и проводимость магнита не моделируются.

Возбуждение и время
Импульс 1: a(t)=sin(2*pi*50*t). Магниту назначен indAmp=1.
M(t)=a(t)*M0. Отрицательная полуволна меняет направление M.
Один полный период: 0 <= t <= 0.020 с.
40 временных интервалов по 0.0005 с; 41 состояние, idtk=0..40.
В amplitudes.txt записан 41 узел, совпадающий с расчётными моментами.
Между узлами решатель применяет кусочно-линейную интерполяцию.
Контроль Mz: 0, +1000, 0, -1000, 0 кА/м при t=0,5,10,15,20 мс.
На начальном шаге M=0 и вихревые токи равны нулю.
Это первый переходный период; установившаяся периодичность не предполагается.
Продолжение синуса после 20 мс таблицей не задано. Для дополнительных периодов
нужно продлить одновременно таблицу импульса и временной диапазон расчёта.

Численные настройки
Полная 3D-постановка; симметрии не используются. Разбиение вдоль X > 1,
длины плиты и магнита различны — условия автоматического 2D не выполняются.
Два физических элемента: 4500 ЭО с неизвестным J и один ЭО с заданной M.
Float64, EPS=1e-6, TAU=0.1. Оба профиля conrab.txt скопированы без изменений
из пользовательского расчёта plate60_tilt_magnet_3d(1).zip.
При 50 Гц и sigma=40 МСм/м оценка глубины проникновения составляет 11.254 мм.
Число MPI-процессов выбирается при запуске в Editor/Solver.

Контроль результата
В Viewer открыть «Инструменты -> Полные токи», элемент 1, и пройти все времена.
Проверять три направления и начальный, средний, конечный слои.
Полный знаковый ток через полное сечение изолированной плиты должен быть
близок к нулю; сумма модулей вкладов может быть ненулевой.
Для подробного контроля остальных слоёв: площадки имеют площадь 4 мм2,
I_x(k)=4*sum(Jx[k,:,:]) А; аналогично для Y и Z, J хранится в А/мм2.
Порядок ЭО: D1 -> D2 -> D3, D3 меняется быстрее.
Изменение Mz можно проверить в MH.h5 по указанным выше пяти моментам.

Состав и запуск
В архиве только новое задание: input3XX и эта документация, без output3XX.
Распаковать каталог plate120_magnet80_sine50_3d в каталог проектов.
Открыть в Editor, выполнить «Проверить модель», сохранить и запустить расчёт.
Структура входных файлов, геометрия штатными функциями Editor, количество
источников и согласование импульса с временной сеткой проверены при подготовке.
Полный расчёт Solver для нового варианта при подготовке не выполнялся.

mhjRecall!(useAmp=true) -> Ist в solver@1035078856e96973e33de7305a4827ca97a04b9a.
