# Исторические материалы опорной задачи MINI

Обновлено: 2026-10-16 20:00 UTC+3.

Этот каталог хранит материалы для проверки происхождения данных и сравнения
результатов. Текущая сборка и запуск OM не используют его содержимое.

- `original-task.zip` — полный переданный владельцем архив
  `stat_TVV320-2D_Iv=1.0n_Ia=1.0n MINI.zip`, сохранённый побайтово, включая
  старые исходные данные, протоколы и результаты HDF5.
- `historical-code.zip` — снимок прежнего FMI-прототипа, конвертера и связанных
  инструкций и проверок из solver. Он предназначен для изучения истории;
  самостоятельный запуск распакованных сценариев не поддерживается.
- `manifest.json` — размер и SHA-256 обоих архивов, commit источников и
  контрольные суммы каждого архивированного исходного файла.

Протокол исходного задания указывает CircuitClient / NLESolver. Эти результаты
не объявляются результатами нативного OpenModelica. Также не утверждается, что
они получены сохранённым здесь снимком FMI-прототипа.

Актуальное задание находится на три уровня выше, в каталоге MINI OM.
Сведения о численных данных и извлечённых токах находятся в
[`../reference.json`](../reference.json).
Текущая процедура сборки, установки и запуска описана в
[HTML-руководстве](https://y26084670-blip.github.io/web-gui/user-guide/index.html#om-client-test-prepare).
