GIF открывается щелчком по миниатюре или значку сразу в развёрнутом окне.
Боковые кнопки ‹ › переключают файлы; стрелки из заголовка убраны.

Левая панель выбора задания доходит до правого края четвёртой вкладки
«Области наблюдения»;
освободившееся место отдано средней панели. Кнопки режима OM и подключения
расположены в одном ряду; отключённая модель отмечена оранжевым фоном.

Банк временных зависимостей и ссылки на его записи названы «Импульсы».
Машинные имена и числовые амплитуды сохранены.

Кнопка «Выбрать в Viewer» также запрашивает переход на вкладку Viewer.
[Выбор и переход](docs/user-guide/index.html#task-cross-selection).

Версия исходников: **4.79.3**.

Кнопка «Отключить/Подключить» сохраняет параметры клиентской модели и переключает
её участие в задании. Фон первой ячейки списка: светло-зелёный — подключена,
оранжевый — отключена. [Порядок работы](docs/user-guide/index.html#om-client-edit).

Панель «Клиентская модель» редактирует параметры и привязки формой, которую задаёт
описание выбранной модели. Катушки выбираются по номеру и именам элементов/областей.
[Параметры и связи](docs/user-guide/index.html#om-client-edit).

На вкладках «Импульсы» и «Траектории» левое меню заменяет таблицу выбранной
записи числовыми значениями из буфера Excel; доступны отмена и повтор.
Фон генераторов временных зависимостей выполнен в мягкой серо-голубой гамме.
[Вставка таблиц](docs/user-guide/index.html#time-table-clipboard).

В окне «Клиентская модель…» строка «Текущая модель задания» показывает модель и конфигурацию
из данных задания. «Шаблон для применения» выбирает пресет для явной замены данных.
[Как определить модель](docs/user-guide/index.html#om-client-edit).

На вкладках «Элементы» и «Области» подсказка ячейки показывает номер строки
для сопоставления с 3D. [Нумерация записей](docs/user-guide/index.html#edit-records).
Штатное меню браузера отключено на всех вкладках; собственные меню приложения
и сочетания клавиш сохраняются. [Правая кнопка мыши](docs/user-guide/index.html#edit-horizontal-scroll).

Пакет OM `circuit` содержит два варианта нейтрали. Число фаз и параллельных
ветвей задаётся перед запуском в пределах собранной вместимости; JSON содержит
только действующие элементы. Загрузите `editor-preset.json` установленного пакета,
чтобы редактор проверял его максимумы. Формат пресета — `clark-om-preset/2`.
[Сборка без каталога задания](docs/user-guide/index.html#om-client-build).

ЭДС OM-клиента задаётся номером импульса вкладки «Импульсы» и коэффициентом
в вольтах; актуальный формат `clark-circuit/2`. В проекте примеров `Open Modelica` доступны
`test_circuit_with_neutral_1` с нулевым проводом и
`test_circuit_without_neutral_1` без него. Второй вариант подготовлен из Fortran-архива:
220 В, добавочные L/R = 0; первый сохраняет 100 В, 100 Гн и 1 Ом.
Канонические входы и самостоятельные опорные результаты хранятся в clark.tests.
[Полный пример и порядок запуска](docs/user-guide/index.html#om-client-test-204).
Если задание не загружено, кнопка «Клиентская модель…» открывает предупреждение
с рекомендацией загрузки. 

Кнопка «Клиентская модель…» под «Выбрать в Viewer» открывает плавающий
редактор OM загруженного для редактирования задания: пресет, параметры модели
и связи с Clark. Доступен дополнительный режим JSON. Ширина окна фиксирована; кнопка разворачивания увеличивает
только высоту; форма прокручивается в оставшейся области.
Для цепи это `circuit-config.json` и `server-config.json`; окно остаётся открытым
при переходе на другие вкладки. Запуск готовой модели — «Запустить OM-клиент»
в окне списка заданий. Кнопка «?» справа от заголовка пресета открывает раздел справки OM. 
[Рабочий процесс](docs/user-guide/index.html#om-client).

При включённой опции «Осесимметричная (AC)» необходимо отключить «Учёт зарядов».
Проверка модели сообщает об ошибке несовместимых настроек; 
[Правило AC/useMED](docs/AI_DATA_CONTRACTS.md#учёт-зарядов--generalusemed).

Команда «Проверить модель» выдаёт ERROR для пустого или пробельного названия
с номером элемента и полем «Название». Смена типа геометрии заменяет прежние параметры 
корректным примером выбранного типа; Undo/Redo восстанавливает тип вместе с геометрией. 
Панель катушки имеет ширину 600 px и подбирает высоту по содержимому.
[Задать геометрию](https://y26084670-blip.github.io/clark-editor/user-guide/index.html#geometry-box).

Панель «Катушка однородного поля» показывает углы локальной СК, использует
L=100 мм по умолчанию. «Раскрытие» задаёт dvi базового сектора (20.0°);
угол локальной симметрии равен dvi, число образов — floor(360/dvi). Геометрия
и соответствующий диапазон заданных токов создаются согласованно. 
При остатке угла панель показывает предупреждение.
Ctrl+A в 3D возвращает начальный наклонный вид с вписыванием.
Удержание пробела над рабочим 3D-окном
включает линзу ×5 радиусом 300 пикселей; колесо меняет только её увеличение.
При вводе текста и в окне просмотра видео пробел сохраняет своё обычное действие.

Ctrl+S на вкладках исходных данных сохраняет модель, включая редактируемую ячейку. В шторке слева
«Характеристики ФММ» доступен генератор таблицы μ=const из 12 точек.
[Создать характеристику](docs/user-guide/index.html#constant-mu-fmm) ·
[Горячие клавиши](docs/user-guide/index.html#reference).
[Создать катушку](https://y26084670-blip.github.io/clark-editor/user-guide/index.html#uniform-field-coil).

В максимизированном кнопкой □ окне GIF соседние кадры плавно смешиваются
в пределах исходных задержек. «Стоп» удерживает текущий переход; восстановление
размера возвращает обычный показ без перезапуска. Последнее открытое задание
и его проект отмечены жёлтым треугольником вправо с красным контуром.
Отметки восстанавливаются при повторном выборе базового каталога.
[Просмотр GIF](docs/user-guide/index.html#task-gifs) ·
[Выбор задания](docs/user-guide/index.html#task-open).
При восстановлении 3D-окна от границ высота следует ширине и пропорциям экрана.

На вкладке выбора задания имеется галерея сохранённых GIF: просмотр в
плавающем окне и удаление после подтверждения. Она показывает файлы выбранного
в списке задания, которое может отличаться от открытого для редактирования.
[Просмотр GIF](https://y26084670-blip.github.io/clark-editor/user-guide/index.html#task-gifs).

Плавающее 3D-окно расширяется от границ до половины доступного размера,
поддерживает ручное изменение размера за все четыре стороны. В меню
элементов и областей добавлен показ «Кроме выделенных».
[Работа с 3D](https://y26084670-blip.github.io/clark-editor/user-guide/index.html#geometry).

Браузерный редактор исходных данных Clark: таблицы, геометрия и материалы,
проверка и сохранение `input3XX`, подготовка списка и запрос запуска локального
решателя. Сам полевой расчёт выполняет установленный Clark.

[Clark E3D Editor](https://y26084670-blip.github.io/clark-editor/) ·

## Требования

Для локальных файлов — Google Chrome Desktop или Microsoft Edge Desktop, HTTPS либо `localhost`, 
File System Access API и разрешение на выбранный каталог. Для знакомства без файлового доступа 
доступна кнопка «Демо».
Публикация сайта не обновляет установленный решатель или локальную LAN-копию.

Node.js 24; зависимости зафиксированы в `package-lock.json`.
Начало разработки: `npm ci`, затем `npm run dev`.

[AI_BUILD_AND_RUNTIME](docs/AI_BUILD_AND_RUNTIME.md).
