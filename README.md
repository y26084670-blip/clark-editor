# Clark E3D Editor

Обновлено: 2026-10-16 15:18 UTC+3.

Текущая версия: **4.55.1**.

Кнопка «Клиентская модель…» под «Показать в Viewer» открывает плавающий
редактор OM загруженного для редактирования задания: пресет, данные модели сверху,
конфигурация обмена снизу. Ширина окна фиксирована; кнопка разворачивания увеличивает
только высоту, а поля JSON заполняют свободное пространство.
Для цепи это `circuit-config.json` и `server-config.json`; окно остаётся открытым
при переходе на другие вкладки. Запуск готовой модели — «Запустить OM-клиент»
в окне списка заданий. Нижняя зелёная кнопка называется «Формирование списка
заданий и запуск приложений»; четыре нижние кнопки имеют одинаковую компактную
высоту при однострочных надписях. Кнопка прежнего Julia-клиента убрана;
сам клиент и его сборка сохраняются.
[Рабочий процесс](docs/user-guide/index.html#om-client).

При включённой опции «Осесимметричная (AC)» необходимо отключить «Учёт зарядов».
Проверка модели сообщает об ошибке несовместимых настроек; корректный
осесимметричный режим не сопровождается предупреждением об отключённых зарядах.
[Правило AC/useMED](docs/AI_DATA_CONTRACTS.md#учёт-зарядов--generalusemed).

Обозначения ВТСП приведены к `HTS`: новые данные используют `hts*` и
`xapLibHTS`; прежние задания читаются с совместимостью.
[Контракт перехода](docs/AI_CLARK_INTEGRATION.md#hts-naming).

Команда «Проверить модель» выдаёт ERROR для пустого или пробельного названия
с номером элемента и полем «Название». Смена типа геометрии
заменяет прежние параметры корректным примером выбранного типа; Undo/Redo
восстанавливает тип вместе с геометрией. Панель катушки имеет ширину 600 px
и подбирает высоту по содержимому.
[Задать геометрию](https://y26084670-blip.github.io/web-gui/user-guide/index.html#geometry-box).

Панель «Катушка однородного поля» показывает углы локальной СК, использует
L=100 мм по умолчанию. «Раскрытие» задаёт dvi базового сектора (20.0°);
угол локальной симметрии равен dvi, число образов — floor(360/dvi). Геометрия
и соответствующий диапазон заданных токов создаются согласованно. Начальное
название катушки — русское. При остатке угла панель показывает предупреждение.
Ctrl+A в 3D возвращает начальный наклонный вид с вписыванием. Ctrl+S на вкладках
исходных данных сохраняет модель, включая редактируемую ячейку. В шторке
«Характеристики ФММ» доступен генератор таблицы μ=const из 12 точек.
[Создать характеристику](docs/user-guide/index.html#constant-mu-fmm) ·
[Горячие клавиши](docs/user-guide/index.html#reference).
[Создать катушку](https://y26084670-blip.github.io/web-gui/user-guide/index.html#uniform-field-coil).

В максимизированном кнопкой □ окне GIF соседние кадры плавно смешиваются
в пределах исходных задержек. «Стоп» удерживает текущий переход; восстановление
размера возвращает обычный показ без перезапуска. Последнее открытое задание
и его проект отмечены жёлтым треугольником вправо с красным контуром.
Отметки восстанавливаются при повторном выборе базового каталога.
[Просмотр GIF](docs/user-guide/index.html#task-gifs) ·
[Выбор задания](docs/user-guide/index.html#task-open).
При восстановлении 3D-окна от границ высота следует ширине и пропорциям экрана.

На вкладке выбора задания имеется галерея сохранённых GIF: просмотр в
плавающем окне и удаление после подтверждения. Она показывает файлы выбранного
в списке задания, которое может отличаться от открытого для редактирования.
[Просмотр GIF](https://y26084670-blip.github.io/web-gui/user-guide/index.html#task-gifs).

Плавающее 3D-окно расширяется от границ до половины доступного размера,
поддерживает ручное изменение размера за все четыре стороны. В меню
элементов и областей добавлен показ «Кроме выделенных».
[Работа с 3D](https://y26084670-blip.github.io/web-gui/user-guide/index.html#geometry).

KPY больше не редактируется и не сохраняется в conrab.txt; решатель использует
внутреннее значение 300. GEO_ANGLE присутствует в обоих профилях новых данных и примеров.

Браузерный редактор исходных данных Clark: таблицы, геометрия и материалы,
проверка и сохранение `input3XX`, подготовка списка и запрос запуска локального
решателя. Сам полевой расчёт выполняет установленный Clark.

## Требования

Для локальных файлов — Google Chrome Desktop или Microsoft Edge Desktop,
HTTPS либо `localhost`, File System Access API и разрешение на выбранный
каталог. Для знакомства без файлового доступа доступна кнопка «Демо».
Публикация сайта не обновляет установленный решатель или локальную LAN-копию.

Практические инструкции с иллюстрациями находятся в **HTML-руководстве**;
оно открывается также синей кнопкой «Документация» на основной панели.

[Проекты и задания](https://y26084670-blip.github.io/web-gui/user-guide/index.html#tasks) ·
[Библиотеки](https://y26084670-blip.github.io/web-gui/user-guide/index.html#material-source) ·
[Контакты MED](https://y26084670-blip.github.io/web-gui/user-guide/index.html#med) ·
[Проверка и сохранение](https://y26084670-blip.github.io/web-gui/user-guide/index.html#validation) ·
[Запуск](https://y26084670-blip.github.io/web-gui/user-guide/index.html#launch).

В левой шторке вкладки «Выбор задания» доступны создание, копирование,
переименование, перенос и удаление задания после подтверждения. [Порядок работы](https://y26084670-blip.github.io/web-gui/user-guide/index.html#tasks).

## Разработка и сборка

Node.js 24; зависимости зафиксированы в `package-lock.json`.
Начало разработки: `npm ci`, затем `npm run dev`.

[AI_BUILD_AND_RUNTIME](docs/AI_BUILD_AND_RUNTIME.md).
