# Контекст решателя CLARK для ИИ

Обновлено: 2026-11-20 20:10 UTC+3.

**[Скачать актуальный Контекст v1.2 (ZIP, 2,70 МиБ)](archives/Solver_Context_v1.2_public_2026-11-20.zip?raw=true)** · [Пошаговый урок в справке Editor](https://y26084670-blip.github.io/clark-editor/user-guide/user.html#solver-context)

С этим ZIP можно открыть новый чат, спросить о CLARK или подготовить задание по эскизу либо FEM-файлу. Внутри есть автономная справка, схемы полей и примеры. Для вопросов о силах и выходных величинах начните с `AI_FORCE_AND_VIEWER.md`. Два комплекта с тремя кубами содержат готовые входы и численные ряды в CSV. Для первого опыта понадобятся чат с обработкой файлов и настольный Chrome или Edge для открытия задания в Editor. Установка решателя понадобится, когда вы захотите рассчитать поле.

## Первый опыт с нуля

1. **Скачайте Контекст** по ссылке вверху. Если GitHub показывает карточку ZIP, нажмите **Download raw file**. Сохраните архив под исходным именем.
2. **Откройте новый чат с ИИ.** Через кнопку прикрепления файлов добавьте скачанный ZIP. Дождитесь появления имени файла в сообщении. При первом опыте свой эскиз или FEM-файл не нужен.
3. **Отправьте текст ниже.** В архиве уже есть куб со стороной 10 мм. ИИ должен подготовить его копию с более мелким разбиением.

   > Прочитай START.txt и AI_SOLVER_CONTEXT.md. Возьми examples/01_prescribed_source. Измени разбиение одного куба с 2×2×2 на 4×4×4. Сохрани геометрию, однородную намагниченность и область наблюдения. Пересоздай данные заданного источника для новой сетки. Верни ZIP с каталогом AI_cube_64, его input3XX и DOCS. Укажи число ШГ и ЭО и выполненные проверки. Расчёт поля не выполняй.

4. **Скачайте ZIP из ответа ИИ.** Внутри должен быть каталог задания `AI_cube_64/` с папками `input3XX/` и `DOCS/`. Если в ответе только текст, попросите приложить проверенные файлы одним ZIP. Если чат не читает исходный архив, порядок передачи отдельных файлов приведён в [уроке](https://y26084670-blip.github.io/clark-editor/user-guide/user.html#context-chat).
5. **Распакуйте задание.** Рекомендуется размещать пользовательские каталоги с проектами в корне несистемного диска, обычно `D:\`. Имя каталога должно начинаться с `clark.`, чтобы Editor добавил его в список каталогов с проектами; имя `clark.app` зарезервировано для приложения. Создайте в Windows папку `D:\clark.projects\Уроки` и распакуйте туда каталог из ответа. Можно выбрать другой несистемный диск с доступом на запись, сохранив префикс `clark.`. Проверьте итоговый путь: `D:\clark.projects\Уроки\AI_cube_64\input3XX\general.txt`. При повторении опыта возьмите новую папку задания.
6. **Откройте [E3D Editor](https://y26084670-blip.github.io/clark-editor/).** В окне «Доступ к проектам» нажмите «Выбрать диск с проектами», укажите корень того же диска, в примере `D:\`, разрешите чтение и запись и нажмите «Продолжить». Выберите `clark.projects` → «Уроки» → `AI_cube_64` → «Загрузить для редактирования». Связать каталоги с решателем можно позднее; в окне Clark выберите тот же диск, в примере `D:\`.
7. **Проверьте результат.** На вкладке «Элементы» включите «Разбиение». Ожидается **один шестигранник (ШГ), разбиение 4×4×4 и 64 элементарных объёма (ЭО)**. На вкладке «Заданные источники» для каждого ЭО должна сохраняться M = (0, 0, 800) кА/м. Нажмите «Проверить модель». Нажмите цветной круг в верхней панели, чтобы прочитать сообщения. После устранения ошибок нажмите «Сохранить модель». На этом первый опыт закончен.

Номер Контекста, версия Editor и версия профиля обозначают три разные вещи. Для нового задания выбирайте верхнюю строку. Для повторения старого опыта сохраните имя использованного ZIP вместе с ответом ИИ. При переходе на новый выпуск откройте новый чат и прикрепите выбранный ZIP. Если продолжаете прежнюю задачу, приложите отдельно её каталог с входными данными и опишите требуемое изменение. В каждом выпуске `source-lock.json` указывает источники, а `manifest.json` — контрольные суммы файлов.

Публичные комплекты содержат открытые документы и модули Editor, учебные примеры и средства проверки. В v1.2 входят также открытые материалы Viewer и результаты расчётов сил версии 2.01.03. Рекомендуемая этим снимком Editor версия установленного решателя — 2.02.00. Для FEM-маршрута используется учебный квадрат с заданной намагниченностью. Встроенная в ZIP копия справки соответствует снимку Editor этого выпуска. В локальной поставке Editor откройте «Документация» → «Контекст решателя для ИИ». И урок, и скачивание текущего ZIP доступны из этой справки.

## Как воспроизвести публичные ZIP

Обычному пользователю достаточно скачать выбранный выпуск. Для проверки сборки разработчику понадобятся полный клон репозитория Editor, Git, Python 3.9+ и Node.js 24. Из корня репозитория выполните `python scripts/build-solver-context.py --check` (в Linux можно использовать `python3`). Сценарий воспроизводит выпуски, сравнивает их с опубликованными ZIP и выводит SHA-256. Для v1.2 он загружает закреплённый открытый снимок Viewer. Для сборки без сети укажите локальный клон с нужным коммитом через `--viewer-repo ПУТЬ`. Для чтения готового ZIP сеть не требуется. Команда без `--check` записывает архивы и копию текущего выпуска для справки. Снимки Editor закреплены по Git-коммитам. Исходники учебных материалов и проверочных программ находятся в [scripts/solver-context](../scripts/solver-context).
