Документация CLARK

Расчёт электромагнитных полей методом интегральных уравнений. В E3D Editor готовят модель, в решателе CLARK выполняют расчёт, в E3D Viewer исследуют поля, токи, силы и потери.

Руководство пользователяОт первого задания до проверки результата. Четыре учебных комплекта с исходными данными. Развитие CLARK с помощью ИИКарта репозиториев, постановка задачи для ИИ и разбор изменения таблицы M(H). ТеорияИнтегральная постановка, слабая токовая схема JWeak1, материалы, контакты и симметрии.
