## От условия к каталогу

1. Зафиксируйте оси и единицы, тела, размеры, материалы, заданные и неизвестные источники, электрические контакты, движение, наблюдения. Помечайте происхождение значений. Для эскиза укажите, с каким отрезком связан опорный размер.
2. Составьте таблицу тел и устойчивых ID крупных ШГ (записей KV). Сохраните отверстия и зазоры. Разрежьте по физической границе, контакту или существенной особенности формы. Запишите причину каждого разреза и погрешность аппроксимации.
3. Задайте внутреннюю сетку dp=[d12,d13,d15] каждого блока. Число ЭО при отсутствии повторений равно произведению этих чисел. При наличии образов отдельно посчитайте геометрические и независимые ЭО по правилам Editor.
4. Сгруппируйте KV по targ. После окончательного порядка пересчитайте ссылки MED и массив MHJ. В MHJ для заданной M или J на каждый независимый ЭО приходится один вектор. Сериализатор сохраняет столбцы компонент подряд. Для однородного M=(0,0,800) и 64 ЭО массив v содержит 64 нуля по X, 64 нуля по Y и 64 значения 800 по Z.
5. Подготовьте один каталог задания с семью файлами input3XX, используемыми локальными материалами и папкой DOCS. Добавьте постановку, единицы, пробные параметры, происхождение данных и отчёт о проверках. Полный внешний размер куба, параметры расположения и заданная намагниченность сохраняются при изменении только сетки.
6. Перечитайте файлы из конечного ZIP. Ниже приведены команды из корня распакованного Контекста, где CASE — путь к каталогу задания, содержащему input3XX. Средства используют Python 3 и Node.js 24 со стандартными библиотеками.
```sh
python3 tools/check_case.py CASE
node --no-warnings --loader ./tools/source-loader.mjs tools/check_geometry.mjs CASE
```
Первая команда проверяет структуру, индексы и длину MHJ. Вторая проверяет исходные ШГ нативными функциями Editor. Для оболочек фактических ЭО и проверки модели целиком откройте задание в Editor. Указывайте конкретные результаты проверок. Для нового задания сохраняйте маркер _nogo.e3d до штатной проверки и сохранения в Editor. Запуск solver и оценка физической точности подтверждаются отдельно.
