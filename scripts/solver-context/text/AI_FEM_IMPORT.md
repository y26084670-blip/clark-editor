# От FEM-геометрии к крупным блокам CLARK

1. Установите формат и версию, единицы, исходные оси, плоский или пространственный режим. Для плоского источника выясните длину и направление экструзии. Параметры возбуждения, материалы, границы, периодичность и состояние поля указывайте отдельно.
2. Из CAD/геометрической части выделите тела, контуры и физические группы. Если предоставлена только сетка, используйте метки областей и инцидентность рёбер/граней. Удалите внутренние рёбра одной однородной области из внешнего контура. Сохраняйте помеченные интерфейсы, отверстия, зазоры и разрывы источников.
3. Аппроксимируйте форму крупными допустимыми ШГ. Сверьте габариты, площадь или объём, положение, связность и контакт. Затем назначьте внутреннее разбиение dp. Обоснуйте отклонения. Мелкая сетка исходной программы удобна для проверки формы.
4. Для FEMM извлеките геометрию и метки из .fem. Сопоставьте выбранный режим, LengthUnits, Frequency, Depth, материалы, цепи и внешние границы. .ans при наличии содержит дополнительные данные сохранённого решения. Для Gmsh проверьте версию и смысл physical groups. Для иной системы используйте документированный экспорт, который удаётся прочитать. Укажите недостающие данные для восстановления физической постановки.
5. Перенос величин сопровождайте единицами и направлением. Заданная M или J, табличная характеристика материала и ранее рассчитанное поле выполняют разные роли. Опишите, чем эквивалентны граничные условия исходной программы и свободнопространственной постановки CLARK.
6. Выдайте исходные данные CLARK, таблицу соответствия областей, происхождение параметров и результаты проверок. Для первого опыта используйте examples/03_fem_square/REQUEST.txt и source.msh. В комплекте есть пример восстановления сечения. Для новой геометрии способ чтения и проверки выбирается по её формату.
