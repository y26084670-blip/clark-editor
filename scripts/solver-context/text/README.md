# Контекст решателя CLARK для ИИ · {VERSION} (публичная редакция)

Обновлено: 2026-11-17 19:51 UTC+3.

Editor {EDITOR} · профиль по эскизу {PROFILE} · 17 ноября 2026. Это материалы для ответа в чате и подготовки каталога задачи. Для расчёта поля используется отдельно установленный решатель CLARK.

1. Сохраните исходный ZIP. Откройте новый чат, который может читать вложения и возвращать файлы. Прикрепите ZIP целиком. В чате с поддержкой локального исполнения кода попросите проверить выходные файлы.
2. Для первого опыта отправьте следующий текст:

> Прочитай START.txt и AI_SOLVER_CONTEXT.md. Возьми examples/01_prescribed_source. Измени разбиение одного куба с 2×2×2 на 4×4×4. Сохрани геометрию, однородную намагниченность и область наблюдения. Пересоздай данные заданного источника для новой сетки. Верни ZIP с каталогом AI_cube_64, его input3XX и DOCS. Укажи число ШГ и ЭО и выполненные проверки. Расчёт поля не выполняй.

3. Скачайте выданный ZIP задания. Рекомендуется размещать пользовательские каталоги с проектами в корне несистемного диска, обычно `D:\`. Имя каталога должно начинаться с `clark.`, чтобы Editor добавил его в список каталогов с проектами; имя `clark.app` зарезервировано для приложения. Создайте `D:\clark.projects\Уроки` и распакуйте задание так, чтобы получился путь `D:\clark.projects\Уроки\AI_cube_64\input3XX\general.txt`. Можно выбрать другой несистемный диск с доступом на запись, сохранив префикс `clark.`. В соседней `DOCS` находится отчёт. Исходный Контекст хранится отдельно.
4. Откройте Editor в настольном Chrome или Edge. Нажмите «Выбрать диск с проектами», выберите корень того же диска, в примере `D:\`, дайте браузеру доступ и нажмите «Продолжить». Выберите каталог clark.projects, проект «Уроки» и задание AI_cube_64. Нажмите «Загрузить для редактирования». При последующем связывании с решателем в окне Clark выберите тот же диск, в примере `D:\`.
5. На вкладке «Элементы» включите «Разбиение». Ожидается одна строка, dp=4×4×4 и 64 ЭО. Проверьте направление и величину заданной M. Нажмите «Проверить модель», прочитайте диагностику и нажмите «Сохранить модель». Для урока с исходными данными установка решателя не требуется.

Если чат не раскрывает архив, локально распакуйте его и приложите START.txt, AI_SOLVER_CONTEXT.md и материалы выбранного примера. Для первого задания потребуются все файлы его input3XX. Сеанс с поддержкой создания файлов может выдать ZIP целиком.

Сведения об индивидуальных проверках и ограничениях приведены в AI_SOLVER_CONTEXT.md. Публичная версия использует открытые документы Editor и синтетические примеры. Происхождение и контрольные суммы файлов указаны в source-lock.json и manifest.json. Полное руководство остаётся доступно внутри архива в reference/user-guide/index.html.
