Учебный FEM-вход для той же геометрии, что и examples/01_prescribed_source. В новом чате приложите этот Контекст и передайте текст REQUEST.txt, указав на source.msh в этой папке. Исходная сетка задана в ASCII Gmsh 2.2. Для этого примера внешняя граница охватывает 100 мм², после экструзии получаются 1000 мм³. Одно прямое тело допускает один KV с восемью ЭО. Это открытый учебный пример с известным ответом.
